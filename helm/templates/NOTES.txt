NOTE: Namespaced mode is enabled (watchNamespace={{ .Values.controller.watchNamespace }}).

In namespaced mode the controller skips webhook certificate generation, CRD
caBundle patching, and the webhook server. Conversion webhooks are only invoked
when the API server needs to translate a stored object between API versions
(e.g. v1alpha1 ↔ v1beta1). If all your CRs are already stored at the current
preferred version this has no effect.

If you do have resources stored at a non-preferred API version, ensure that
either a cluster-scoped agent-sandbox instance or external cert management is
serving the conversion webhooks in this cluster.

Apply the following Role and RoleBinding in each watched namespace:
